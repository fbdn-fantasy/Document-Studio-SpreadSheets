# Document Studio Spreadsheets

**Document Studio Spreadsheets** is a free, open-source desktop spreadsheet application for Windows and Linux, designed for personal, educational, and business use.

From managing household budgets and planning projects to tracking business finances and payroll, it provides an easy way to organize information, perform calculations, and manage records.

The application also includes a **dedicated business management interface**, allowing users to enter financial information, track payments, and manage monthly records without manually editing spreadsheet cells.

All workbooks are stored locally, with no cloud services or accounts required.

## Features

- **Spreadsheet Editor:** Create, edit, and manage spreadsheets with formulas and calculations.
- **Workbook Templates:** Ready-made templates for personal budgets, gradebooks, project planning, and more.
- **Custom Workbooks:** Create workbooks with your own worksheets and layouts.
- **Dedicated Business Interface:** Easily enter and manage business information through dedicated forms instead of manually editing spreadsheet cells.
- **Income & Expense Tracking:** Record invoices, purchases, fuel expenses, and other business transactions.
- **Payment Tracking:** Mark outgoing payments as paid and incoming payments as received, making it easy to identify outstanding amounts.
- **Monthly Rollover:** Carry outstanding income and unpaid expenses into the following month for continued tracking.
- **Payroll Management:** Track employee pay and attendance with configurable tax rates.
- **Linked Business Records:** Automatically update connected worksheets and totals when recording transactions.
- **Automatic Saving:** Save changes to open workbooks automatically every minute.
- **Excel & OpenDocument Support:** Open XLSX and ODS spreadsheets.
- **Offline Operation:** No accounts, cloud services, or internet connection required for normal use.
- **Built-in Updater:** Manually check for, download, and install new updates directly from the application.

## File Compatibility

| Format | Support |
|---|---|
| XLSX | Open and save copies |
| ODS | Open and save copies |

**Note:** Complex formatting, charts, and pivot tables may not be preserved when saving imported spreadsheets. ODS formatting is not preserved.

## Download & Installation

Document Studio Spreadsheets is available for **Windows and Linux**.

| Platform | Available Format |
|---|---|
| Windows (x64) | EXE Installer |
| Fedora / RPM-based Linux | RPM Package |
| Debian / Ubuntu-based Linux | DEB Package |
| Other compatible Linux distributions | TAR.GZ Installer |

All packages target 64-bit Intel and AMD systems.

Download the latest available version from the **[GitHub Releases](../../releases)** page.

*Note: Linux builds require glibc 2.39 or newer, GTK 3, and WebKitGTK 4.1.*
